# 🎮 تحدي رجا - لعبة أسئلة جماعية ذكية

لعبة أسئلة وأجوبة تفاعلية للعائلة والأصدقاء، مع بنك أسئلة متزامن سحابياً وإدارة احترافية.

## ✨ الميزات الرئيسية

- 🌍 **نسخة ويب كاملة** - تعمل على أي جهاز برقم سري آمن
- ☁️ **مزامنة سحابية فورية** - جميع البيانات تتحدث تلقائياً عبر Supabase
- 📚 **2,160 سؤال** - موزّعة على 36 فئة، كل فئة 20 سؤالاً لكل مستوى صعوبة
- 👥 **فريقان** - محلياً على جهاز واحد، أو أونلاين من أجهزة متعددة برمز روم
- 🎯 **نظام نقاط متقدم** - ثلاث مستويات صعوبة (سهل/متوسط/صعب)
- 🛡️ **وسائل مساعدة ذكية** - الفخ، استريح، الحفرة، الصديق، جاوب جوابين
- ⚙️ **لوحة تحكم احترافية** - إدارة كاملة للأسئلة والفئات والنقاط

## 🎮 كيفية اللعب

### المرحلة 1: إعداد الفرق
1. اكتب اسم كل فريق
2. اختر 3 وسائل مساعدة لكل فريق
3. اضغط "التالي"

### المرحلة 2: اختيار الفئات
1. اختر الفئات التي تريد اللعب بها
2. يمكنك إضافة فئات مخصصة
3. اضغط "ابدأ اللعبة"

### المرحلة 3: اللعب
1. اختر سؤال من اللوحة (النقاط تحدد الصعوبة)
2. اقرأ السؤال وحاول الإجابة
3. اضغط "عرض الإجابة" لرؤية الحل الصحيح
4. أعط النقاط للفريق الفائز
5. تابع مع الأسئلة الأخرى

## ⚙️ لوحة الإدارة

### 📚 إدارة الأسئلة
- **إضافة سؤال جديد**: اختر فئة ومستوى صعوبة، ثم أضف السؤال والإجابة
- **حذف سؤال**: اضغط على ✕ بجانب السؤال
- **تصدير**: احفظ جميع البيانات في ملف JSON
- **استيراد**: أضف أسئلة من ملف JSON

### 📂 إدارة الفئات
- **إضافة فئة**: أضف فئة جديدة للعبة
- **حذف فئة**: احذف فئة غير مستخدمة
- **إرجاع الافتراضية**: استعيد الفئات الأصلية

### 🏆 إدارة النقاط
- عدّل نقاط السؤال السهل (افتراضي: 100)
- عدّل نقاط السؤال المتوسط (افتراضي: 250)
- عدّل نقاط السؤال الصعب (افتراضي: 400)

### ☁️ المزامنة السحابية
- **حالة الاتصال**: تحقق من حالة الاتصال بـ Supabase
- **مزامنة يدوية**: اضغط "مزامنة الآن" لتحديث البيانات
- **التصدير/الاستيراد**: احفظ نسخة احتياطية من كل شيء

## 🐛 استكشاف الأخطاء

### الموقع لا يحمل
- تحقق من المتصفح (استخدم نسخة حديثة)
- امسح الـ cache
- اختبر في متصفح مختلف

### المزامنة لا تعمل
- تحقق من اتصال الإنترنت
- تحقق من إعدادات Supabase
- اضغط "مزامنة الآن" من لوحة الإدارة

### الأسئلة لا تظهر
- تأكد من إضافة أسئلة في لوحة الإدارة
- تحقق من أن الفئة صحيحة
- حاول تصدير واستيراد البيانات
